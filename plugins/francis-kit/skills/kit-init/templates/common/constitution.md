# {{TITLE}} Constitution

## Core Principles

### I. Spec before code
No feature is built from a spec whose status is not `Approved`. Only a person sets `Approved`.

### II. Tests are the proof
A change is done when its tests run and their output is shown. A test that cannot fail proves nothing.

### III. One source for each fact
A rule, a number or a decision lives in one place. Everything else points to it.

### IV. The simplest thing that meets the spec
No abstraction before its second use, nothing the spec did not ask for, and the shape the project already has before a new one.
